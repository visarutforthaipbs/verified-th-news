# ผลทดสอบโมเดล Embedding สำหรับ BERTopic ภาษาไทย

**วันที่ทดสอบ:** 14 กันยายน 2569  
**ข้อมูล:** 14,429 บันทึก / 13,377 ข้อความไม่ซ้ำ  
**คำถาม:** การเปลี่ยนจาก `multilingual-e5-small` แบบ `passage:` ไปเป็น E5 แบบ `query:` หรือ `paraphrase-multilingual-MiniLM-L12-v2` ทำให้ผลวิเคราะห์ข่าวดีขึ้นหรือไม่

## คำตอบสั้น

**ยังไม่ควรเปลี่ยน production เป็น MiniLM และยังไม่ควรเปลี่ยน prefix ของ E5 ในงานรอบนี้**

MiniLM ให้คะแนนการแยกกลุ่มเชิงเรขาคณิตสูงที่สุด แต่คลัสเตอร์เปลี่ยนตาม seed มากที่สุด ทิ้งข้อมูลเป็น noise มากที่สุด และรักษากลุ่มข่าวสำคัญที่ใช้เขียนสองสกู๊ปได้น้อยกว่าโมเดลเดิมอย่างชัดเจน สำหรับงานข่าวซึ่งต้องการผลที่ตรวจซ้ำและตามรอยได้ โมเดลเดิม `E5 + passage:` จึงยังเป็นตัวเลือกที่ปลอดภัยที่สุด

ข้อสรุปนี้เป็นการตัดสินสำหรับ **ข้อมูลและพารามิเตอร์ชุดนี้** ไม่ใช่คำตัดสินว่าโมเดลหนึ่งดีกว่าอีกโมเดลในทุกงาน

## ผลหลัก

| ตัวชี้วัด | E5 `passage:` เดิม | E5 `query:` | MiniLM |
|---|---:|---:|---:|
| ความนิ่งเมื่อเปลี่ยน UMAP seed (mean ARI; ยิ่งสูงยิ่งดี) | **0.839** | 0.537 | 0.496 |
| จำนวนคลัสเตอร์ที่ seed 42 | 64 | 90 | 105 |
| ข่าวที่เป็น noise (ระดับบันทึก; ยิ่งต่ำยิ่งดี) | **16.11%** | 24.27% | 27.98% |
| Silhouette ใน embedding เดิม (ยิ่งสูงยิ่งดี) | 0.047 | 0.070 | **0.125** |
| แยกขอบเขตเรื่องคนข้ามชาติจาก silver labels (ROC AUC) | 0.931 | **0.939** | 0.901 |
| ความต่อเนื่องเฉลี่ยของ 7 topic ที่ใช้ในโครงข่าว (Jaccard) | **1.000** | 0.522 | 0.367 |
| ข้อความเกินเพดานโมเดล | 0% | 0% | 0% |

### อ่านผลอย่างไร

- **E5 `passage:` ชนะด้านความทำซ้ำได้**: ARI เฉลี่ย 0.839 สูงกว่าอีกสองแบบมาก เมื่อเปลี่ยนเพียง seed ของ UMAP โครงสร้างคลัสเตอร์ยังใกล้เดิม
- **MiniLM ชนะเพียงด้าน separation**: silhouette 0.125 บอกว่าในพื้นที่ embedding ของ MiniLM กลุ่มที่ HDBSCAN เลือกแยกจากกันชัดกว่า แต่ผลนั้นแลกกับ 105 กลุ่ม, noise เกือบ 28% และความนิ่งต่ำ
- **E5 `query:` ช่วยงานคัดคนข้ามชาติเล็กน้อย**: ROC AUC เพิ่มจาก 0.931 เป็น 0.939 แต่ labels ชุดนี้มาจากการอ่านและตัดสินเบื้องต้นของผู้ช่วย ไม่ใช่ gold standard จากนักข่าวสองคน ความต่าง 0.008 จึงยังไม่พอให้เปลี่ยน pipeline
- **MiniLM ไม่ได้แพ้เพราะตัดข้อความ**: ข้อความยาวที่สุดในชุดนี้มี 83 token ต่ำกว่าเพดาน 128 token ของ MiniLM

## ผลต่อสองสกู๊ปข่าว

ทดสอบว่าคลัสเตอร์ใหม่รักษาสมาชิกของ Topic 1, 2, 4, 7, 11, 28 และ 49 ในรอบตีพิมพ์เดิมได้เพียงใด โดยจับคู่กับคลัสเตอร์ใหม่ที่มี Jaccard สูงสุด

| Topic เดิม | E5 `query:` | MiniLM |
|---:|---:|---:|
| 1 ลงทุน/ปันผล | 0.419 | 0.419 |
| 2 ใบขับขี่ออนไลน์ | **0.909** | 0.294 |
| 4 รักษา/ฆ่าเชื้อโควิด | **0.686** | 0.620 |
| 7 ข่าวผู้ติดเชื้อ | **0.633** | 0.440 |
| 11 อ้างคืนเงินผู้เสียหาย | **0.838** | 0.466 |
| 28 กัมพูชา/ด่าน/แรงงาน | 0.127 | **0.277** |
| 49 ต่างด้าว/สัญชาติ | 0.043 | **0.055** |

กลุ่มกัมพูชา–ชายแดนและต่างด้าว–สัญชาติแตกหรือถูกรวมใหม่อย่างแรงในทั้งสองโมเดลทางเลือก การเปลี่ยนโมเดลตอนนี้จึงอาจเปลี่ยนเส้นเรื่องของบทความคนข้ามชาติโดยที่ยังไม่มีมนุษย์ตรวจว่ากลุ่มใหม่มีความหมายดีกว่าจริง

## คำตัดสิน

1. **คง `intfloat/multilingual-e5-small` + `passage:` สำหรับผล production และสองสกู๊ปปัจจุบัน**
2. เก็บ E5 `query:` เป็น challenger สำหรับการทดลองครั้งถัดไป เพราะช่วย silver-label migrant screening เล็กน้อยและลดความสัมพันธ์ระหว่าง topic กับสำนักข่าว แต่ต้องแก้ปัญหา seed stability และ noise ก่อน
3. ไม่เลือก MiniLM สำหรับการจัดคลัสเตอร์หลักรอบนี้ แต่สามารถทดลองเป็นโมเดลเสริมสำหรับค้นข้อความคล้ายกันหรือเสนอ candidate ให้มนุษย์ตรวจได้
4. ก่อนเปลี่ยน production ให้สร้างชุดทดสอบที่นักข่าวอย่างน้อย 2 คนลงรหัส 300–500 ข่าว ครอบคลุมสุขภาพ การเงิน คนข้ามชาติ ชายแดน และ noise แล้ววัด topic purity, retrieval recall และความสอดคล้องระหว่างผู้ลงรหัส

## ข้อจำกัด

- ไม่มี gold-standard topic labels ที่ลงรหัสโดยนักข่าวอิสระจากกัน ผลนี้จึงเป็น **model-selection benchmark** ไม่ใช่การพิสูจน์ความจริงของ narrative
- Silhouette และ cosine compactness เปรียบเทียบข้าม embedding space ได้เพียงเชิงวินิจฉัย ไม่ควรใช้เป็นคะแนนตัดสินเดี่ยว
- การเทียบ continuity ให้ความสำคัญกับความต่อเนื่องของงานเดิมโดยตั้งใจ จึงไม่สามารถบอกว่าคลัสเตอร์ใหม่ที่ต่างออกไป “ผิด” ได้ ต้องอ่านตัวอย่างโดยมนุษย์
- ปี 2558 และ 2569 เป็นปีข้อมูลบางส่วน แต่ไม่กระทบการทดสอบ embedding โดยตรง เพราะทุกแขนใช้ corpus เดียวกัน
