# TypeSafe pilot สำหรับ Story 2

ผลประเมินหลังรันจริงอยู่ที่ [PILOT_EVALUATION_TH.md](PILOT_EVALUATION_TH.md) และรายการที่ Jev เห็นต่างจากการคัดเดิมอยู่ที่ [pilot_scope_disagreements.csv](pilot_scope_disagreements.csv)

## ใช้ตรงไหนในงานนี้

TypeSafe Jev เป็น **ผู้ช่วยคัดกรองรอบที่สอง** สำหรับแฟ้มผู้สมัคร 332 รายการ ไม่ใช่โมเดลค้นหัวข้อแทน BERTopic และไม่ใช่ผู้ตรวจสอบข้อเท็จจริง

เอกสารปัจจุบันของ TypeSafe ระบุว่า Jev รับข้อความภาษาไทยได้ แต่ภาษาอังกฤษเป็นภาษาหลักที่มีความแม่นยำดีที่สุด ดังนั้นผลภาษาไทยของโครงการนี้ต้องผ่านการเทียบกับชุดที่นักข่าวลงรหัสเองก่อนนำไปใช้จริง

แต่ละระเบียนถูกส่งเป็น `claim_text` และ `title` โดยไม่ส่ง `assistant_scope`, `human_scope` หรือป้ายกำกับเดิมเข้าโมเดล เพื่อให้ผลเป็นอิสระพอสำหรับใช้ชี้จุดที่ควรตรวจซ้ำ

คำถาม 10 ข้อถูกส่งพร้อมกัน:

1. อยู่ในขอบเขตเรื่องแรงงานข้ามชาติ/ผู้ลี้ภัย/คนข้ามแดนหรือไม่ (`Noul`)
2. ขอบเขตหลัก 4 กลุ่ม (`Choice`)
3. ประเด็นหลัก 8 กลุ่ม (`Choice`)
4. หลักฐานจากชื่อและข้ออ้างชัดเพียงใด (`Choice`)
5. กรอบโรคและการแพร่เชื้อ (`Noul`)
6. กรอบแย่งงาน/เศรษฐกิจ (`Noul`)
7. กรอบได้รับสิทธิหรือสวัสดิการเกินควร (`Noul`)
8. กรอบภัยต่ออธิปไตย/ความมั่นคง (`Noul`)
9. กรอบอาชญากรรม (`Noul`)
10. กรอบเหยื่อการเอาเปรียบ (`Noul`)

## สถานะรอบนี้

ไฟล์ `pilot_request_payloads.jsonl` เป็นคำขอจริงที่พร้อมส่งสำหรับตัวอย่างแบบแบ่งชั้น 24 รายการ จากทั้ง 4 สถานะเดิม และกระจายตัวอย่างของแต่ละกลุ่มตามช่วงเวลา ขณะสร้างแฟ้มนี้ยังไม่มี `TYPESAFE_API_KEY` จึง **ยังไม่มีผลจาก Jev** และไม่มีการเขียนทับผลวิเคราะห์เดิม

รันแบบเตรียม payload โดยไม่เรียก API:

```bash
.venv/bin/python scripts/typesafe_migrant_pilot.py
```

รัน pilot จริงหลังตั้งค่า key:

```bash
TYPESAFE_API_KEY='...' .venv/bin/python scripts/typesafe_migrant_pilot.py --live --limit 24
```

ผลจริงจะอยู่ใน `pilot_results.csv` พร้อม `typesafe_review_priority` และเหตุผลที่ต้องตรวจซ้ำ ทุกคอลัมน์จากโมเดลขึ้นต้นด้วย `typesafe_`; ช่อง `human_scope`, `human_frame`, `human_review_status` ต้องให้นักข่าวเป็นผู้กรอกเท่านั้น

ตัวเรียก API จะลองใหม่แบบหน่วงเวลาเมื่อพบปัญหาชั่วคราว เช่น HTTP 429/5xx และจะบันทึกทั้งรุ่นโมเดลจริงที่ตอบกับ fingerprint ของชุดคำถาม เพื่อไม่ให้ผลต่างรุ่นหรือคำถามต่างชุดถูกนำมาปนกันโดยไม่ตั้งใจ

## เกณฑ์ตัดสินว่าจะใช้ต่อหรือไม่

ก่อนใช้กับ 332 รายการทั้งหมด ให้ผู้สื่อข่าวตรวจชุด pilot โดยไม่เห็นป้ายเดิม แล้ววัดอย่างน้อย:

- precision/recall ของการคัดเข้าเรื่อง Story 2
- macro-F1 ของ 4 กลุ่มขอบเขต
- ความแม่นและความสอดคล้องระหว่างผู้ตรวจสำหรับกรอบเรื่องแต่ละกรอบ
- calibration แยกตามช่วงความน่าจะเป็น/ความมั่นใจ
- error rate แยกตามปี สำนักข่าว และข้อความสั้น/กำกวม

ค่า confidence หรือ probability ใช้เรียงลำดับการตรวจได้ แต่ไม่ใช่หลักฐานว่าคำตอบถูก ต้องกำหนด threshold จากผล pilot ที่มี human gold labels เท่านั้น
