# Fake News Lab — design system

**ห้องปฏิบัติการข่าวปลอม / FAKE NEWS LAB**
Implementation of brand guide v1.0 (พ.ค. 2568). Written 2026-08-01.

Fake News Lab is the parent organisation. TH Verify / เช็กก่อนเชื่อ is its
product, and everything the product ships — the public check page, the labelling
room, every report and PDF — is dressed in this system.

> **Tagline:** ความจริงต้องมีโครงสร้างพื้นฐาน — *truth needs infrastructure*

## Files

| path | what it is |
|---|---|
| `assets/brand/fnl-design-system.css` | the whole system. One file, no dependencies, no webfonts, no CDN, no network requests at all. |
| `assets/brand/fnl-logo.svg` | primary mark — the X, red over white, with the halftone dissolve |
| `assets/brand/fnl-logo-horizontal.svg` | horizontal lockup: mark + ห้องปฏิบัติการข่าวปลอม + FAKE NEWS LAB |
| `assets/brand/fnl-logo-icon.svg` | icon only, halftone removed so it survives 24px |
| `assets/brand/fnl-logo-mono.svg`, `fnl-logo-horizontal-mono.svg` | monochrome (`currentColor`) |
| `scripts/_brand.py` | Python helper the report builders use: `document()`, `cover()`, `chip()`, `sys_rule()`, `footer()`, `mark()` |

### How a page gets the stylesheet

There are exactly two delivery paths, and both keep a single source of truth.

* **Generated reports** (`scripts/build_*.py`) call `_brand.document()`, which
  reads `fnl-design-system.css` at build time and inlines it. The outputs are
  single files handed to clients and printed to PDF over `file://`; a relative
  `<link>` would break the moment the file moved.
* **Served pages** (`src/th_verify/static/index.html`, `review.html`) are
  returned by FastAPI's `FileResponse` with no static mount, so they cannot link
  to anything either. They carry a copy inside
  `<style data-fnl-design-system>`, regenerated by:

  ```bash
  python scripts/_brand.py sync-static
  ```

  **Run that after every change to the stylesheet.** Do not hand-edit the
  generated block, and do not put the string `data-fnl-design-system` in prose
  near it — the injector anchors on that marker.

## Palette

Five values. They are transcribed from the guide and are not open to
adjustment.

| token | hex | name | role |
|---|---|---|---|
| `--fnl-black` | `#000000` | Infra Black | the base. **Backgrounds are black, always.** |
| `--fnl-red` | `#F20D1B` | Signal Red | urgency, alerts, emphasis, calls to action |
| `--fnl-white` | `#F2F2F2` | Field White | primary text |
| `--fnl-yellow` | `#FFD400` | Alert Yellow | **indicators only** — markers, highlights, UI accents, "investigate" affordances. Never body text. |
| `--fnl-gray` | `#7A7A7A` | Grid Gray | secondary/muted text, grid lines |

Derived neutrals (`--fnl-surface-1/2`, `--fnl-line*`, the `*-wash` fills) are
steps on the black→Grid Gray ramp. Nothing new is invented.

One extra token exists for a practical reason: `--fnl-signal-ink` is Alert
Yellow *in its text role* (mono labels, `+42%` markers, highlighted figures).
It is split out so the print-economy variant can re-point yellow-as-ink to a
legible ochre while yellow-as-fill keeps its exact hex. Use `--fnl-yellow` for
fills and rules; use `--fnl-signal-ink` when yellow is being read as text.

### Colour decisions taken here that the guide did not spell out

* **Links are Field White with a grey underline, red on hover.** A claims table
  where every cell is a link would otherwise be a wall of red, and red would
  stop meaning "emphasis".
* **Verdict colours** map onto palette roles rather than a traffic-light
  scheme, because the palette has no green: `ข่าวปลอม`/scam = Signal Red,
  `บิดเบือน` = Alert Yellow (a qualified verdict is an indicator), `ข่าวจริง` =
  Field White (a plain statement), `ดัดแปลง`/unknown = Grid Gray.
* **Table header rules are red**, section rules are red, and the highlighted
  cell in a data table is yellow. A highlighted number is an indicator, not
  body text, so yellow is in role.

## Typography

Three tiers, all self-hosted-free — no webfont is loaded, because these pages
render offline and in headless Chrome, and because the public page promises not
to log queries (a Google Fonts request would leak the visitor's IP anyway).

| tier | token | stack |
|---|---|---|
| heading | `--fnl-font-head` | Sarabun → IBM Plex Sans Thai → Noto Sans Thai → Thonburi → system, weight 800, tracking −0.01em |
| body | `--fnl-font-body` | same stack, weight 400 |
| mono | `--fnl-font-mono` | ui-monospace → SF Mono → IBM Plex Mono → Menlo → **Sarabun / Noto Sans Thai** → monospace |

Two things to know:

* The mono stack ends in *proportional Thai faces on purpose*. Monospace fonts
  have no Thai glyphs; without that tail, Thai inside a mono metadata label
  renders as tofu. Latin still lands on the mono face, Thai falls through.
* The guide asks for a **geometric, squarish** heading face. No such face can be
  assumed present offline, so the heading tier is the same family at weight 800
  with tight tracking, and squareness is carried by the layout instead — zero
  radii, hard rules, mono system labels. If a licensed display face is ever
  installed on the render hosts, add it at the front of `--fnl-font-head` and
  nothing else needs to change.

**Line height for Thai body copy is 1.68 and that is a floor, not taste.** Thai
stacks vowels above consonants and tone marks above those; tighter leading makes
marks collide with the line above.

Scale: `--fnl-fs-display / h1 / h2 / h3 / body / small / meta / micro`, all in
`rem`. In print the root font-size becomes `10.5pt`, so the whole scale
re-proportions for paper in one move, and the display sizes are additionally
reduced (see *Print* below).

## Visual language

The guide documents five elements. All five exist as CSS, verified rendering in
Chrome:

1. **พิกเซลฮาล์ฟโทน — pixel halftone.** `.fnl-halftone` (+ `--dense`,
   `--sparse`, `--red`, `--yellow`, `--fade`, `--fade-right`). A CSS
   radial-gradient dot matrix — no image files, prints correctly.
2. **แถบตัว X — X bars.** `.fnl-x` is an inline-text-sized mark in pure CSS
   (`--mono` and `--lg` variants). Anything larger uses the SVG.
3. **วงเล็บ UI — UI brackets.** `.fnl-frame` draws all four corner brackets from
   eight gradient arms — no extra DOM. Variants `--red --white --gray --lg
   --tight`. The padding *is* the clear space; do not go below `--fnl-space-4`.
4. **กริดและสเกล — grid and scale.** `.fnl-sys` (a `SYS // 001` mono label with a
   hairline running to the edge), `.fnl-meta`, `.fnl-metablock`, `.fnl-scale`
   (`00 — 50 — 100` with tick marks), `.fnl-ticks`.
5. **สัญญาณสีเหลือง — yellow signals.** `.fnl-chip` with `+` by default and
   `--alert` (`!`), `--arrow` (`→`), `--target` (`⌖`), `--mute` (`·`),
   `--plain`, `--solid`; plus `.fnl-mark`, `.fnl-arrow`, `.fnl-caution`
   (hazard stripes).

## Components

Cover (`.fnl-cover*`), section divider (`.fnl-divider`), stat tiles
(`.fnl-stats` / `.fnl-stat` with `--alert --signal --key`), tables (element-level
plus `td.hl`), pull quotes (`blockquote`, `.fnl-quote--display`,
`.fnl-quote__cite`), callouts (`.fnl-note`, `--signal`, `--alert`),
`.fnl-emph-block`, data bars (`.fnl-bar-row*`), buttons (`.fnl-btn`, `--ghost`,
`--float`), form field (`.fnl-field`, `.fnl-select`), progress (`.fnl-meter`),
footer (`.fnl-footer`), A4 sheet (`.fnl-page`), document column (`.fnl-doc`,
`--narrow`, `--wide`).

### The report component layer (section 06 of the CSS)

The existing report builders emit their own long-standing class names —
`.page .rpt-header .rpt-title .pill .sec-title .timeline .cb-row .src-row
.trend-tbl .insight .method .rpt-footer .dl-btn`. Those names are styled from
the tokens in section 06 instead of being renamed. That was a deliberate
trade: the markup is dense Thai-bearing f-string HTML and rewriting every class
name is the highest-risk edit available in this repo for zero visual gain.
**New markup should use the `fnl-` components.**

### The feature article layer (section 09 of the CSS)

The news-feature rendering of a report (`scripts/build_issue_feature.py`) —
`.fnl-article .feat-hero .feat-headline .feat-dek .feat-lead .feat-sec
.feat-cases .feat-case .feat-box .feat-actions .feat-slot`. Unlike section 06
this markup is new, so it is `fnl-`/`feat-` prefixed and composed from the
tokens throughout.

Two things in it are decisions rather than styling:

* **One markup, two surfaces.** On screen the article is a single reading
  column; in print the same element becomes two columns (`column-count: 2` at
  A4, because 184mm is far too wide a measure for Thai body text), with the
  hero, figures, case grid, boxes and pull quotes spanning both. There is no
  print-only markup — nothing to keep in sync.
* **No drop cap.** A Thai first letter carries vowels above and tone marks above
  those; `::first-letter` takes only the base consonant and leaves the marks
  behind at body size, shearing the glyph apart. The lead is set apart by size
  and a red rule instead.

`.feat-slot` — the unfilled analyst slot — is deliberately loud (dashed yellow
on a yellow wash). A draft has to stay recognisable as a draft after someone
forwards the PDF.

## Print / PDF

Reports are printed at A4 by headless Chrome (via `scripts/_pdf.py`, which is
the single place those flags live):

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=out.pdf file:///abs/path.html
```

What the system does for that path, and why:

* **`@page { size: A4; margin: 14mm 13mm; background: #000000 }`.** The page
  *box* is painted, not just the body. Chrome does **not** propagate the root
  element's background into the `@page` margin area — a black document printed
  that way comes out as a black column floating in a white frame. Painting the
  page box is what makes Infra Black full-bleed while content keeps proper
  margins on every page. (`@page` cannot be scoped to a class, so the light
  variant appends its own `@page { background: #FFFFFF }` — see
  `_brand.document()`.)
* **`print-color-adjust: exact`** on `html`, `body` and every element, or Chrome
  drops the backgrounds and the report prints as white-on-white.
* **Root font-size becomes `10.5pt`** and the display sizes drop
  (`--fnl-fs-display: 1.95rem`). This is not cosmetic: a Thai headline has no
  spaces to break at, so an over-large display size does not wrap politely — it
  runs off the right edge of the sheet and is clipped. `overflow-wrap:
  break-word` on headings is the backstop.
* **Tables** may flow across pages (`break-inside: auto`) but a **row never
  splits** and `thead` repeats on every page (`display: table-header-group`).
  Stat tiles, quotes, notes and figures never split.
* Floating buttons and anything marked `.fnl-no-print` are hidden.

### Print economy (opt-in light variant)

Black A4 is expensive on a desk printer. There is exactly one sanctioned light
rendering and **it is never applied automatically**:

```bash
python scripts/build_weekly_fakenews_report.py --print-economy
python scripts/build_issue_report.py migrant --print-economy
```

which sets `class="fnl-print-economy"` on `<html>`. It re-points the neutral
ramp to paper, keeps Signal Red and Alert Yellow at their exact hex values,
moves yellow out of the text role, and flips the mark's Field White bar to ink
so the X does not disappear on white. The brand is not silently inverted — if
you want light, you ask for it.

## Logo use

Three lockups, as the guide defines them:

* **primary mark** — the X alone, with the halftone dissolve at the outer ends
* **horizontal lockup** — mark + ห้องปฏิบัติการข่าวปลอม (heading tier) +
  `FAKE NEWS LAB` (mono, tracked)
* **icon** — the X alone, halftone removed

Construction: two crossing bars at ±45°, Field White on the "/" axis and Signal
Red on the "\\" axis, red painted over white at the crossing. The dissolve is
six rows of dots per end, shrinking in radius and opacity and dropping columns
as they travel — the density gradient the guide describes.

### Incorrect use (from the guide)

* **ห้ามยืด** — do not stretch. Scale proportionally only; never set `width` and
  `height` to a non-square ratio on the mark.
* **ห้ามเปลี่ยนสี** — do not recolour. Red and white are the mark. If you need a
  single colour, use `fnl-logo-mono.svg`, which is `currentColor` throughout.
* **ห้ามหมุน** — do not rotate. The X is already at 45°; rotating it turns it
  into a `+`, which in this system is a yellow signal marker and means something
  else entirely.
* **ห้ามใส่เอฟเฟกต์** — no glow, drop shadow, bevel, gradient or outline.
* **ห้ามวางชิดเกินไป** — respect clear space: **one X-bar width** (22/120 of the
  mark's height, i.e. ~18% of its size) free on all four sides.

### Minimum sizes

* icon: **24px** — below this the mark stops reading as an X. This is why
  `fnl-logo-icon.svg` drops the halftone: at 24px the dots collapse into mud.
* horizontal lockup: **160px** wide — below this the Thai wordmark is unreadable.

### The wordmark is live text

`fnl-logo-horizontal.svg` sets ห้องปฏิบัติการข่าวปลอม as `<text>` in the brand
font stack rather than as outlines. It therefore shapes Thai correctly anywhere a
Thai font exists, and stays editable — but **outline it before sending the file
to a commercial printer**, where font availability is not guaranteed.

`fnl-logo-mono.svg` uses `currentColor` for every shape. It must be **inlined**
in the host document (or tinted with CSS `color`); loaded through `<img>` or
`<object>` it has no colour to inherit and renders black on black.

## Tone of voice

Wanted: ชัดเจน (clear) · สงบ (calm) · คม (sharp) · ชวนคิด (thought-provoking) ·
เพื่อประโยชน์สาธารณะ (public-interest) · ชวนลงมือทำ (action-prompting).

Avoided: ไม่ปลุกตื่นตระหนก (no panic-mongering) · ไม่ล้อเหยื่อ (never mock
victims) · ไม่แบ่งขั้วทางการเมือง (non-partisan) · ไม่ใช้ศัพท์ยากเกินจำเป็น (no
unnecessary jargon).

**Communication formula:** ส่งสัญญาณความเสี่ยง → แสดงหลักฐาน → บอกว่าควรทำอะไรต่อ.
In practice, that is why `cover()` takes a `chips` argument: the chip row at the
top of a report is the risk signal, the tables under it are the evidence, and
the closing note says what to do next.

The colour system carries the same rule. `related` on the public check page is
Alert Yellow, not Signal Red: it is a pointer at relevant records, not an alarm.
Reserving red for real alerts is what keeps red meaningful.
